# MY_PORTFOLIO_SITE | Jackson Kimotho

Welcome to the data scientist and AI engineering portfolio for **Jackson Kimotho**. 

This repository contains the source code for a sleek, highly-optimized single-page web application. It features customized CSS-variable multi-theme support, robust layout designs for project highlights, and integrated contact form routing.

### 🚀 Tech Stack
- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS (v4)**
- **Motion (Framer Motion)**
- **Lucide Icons**

### 💻 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server locally:
   ```bash
   npm run dev
   ```

3. Convert images to WebP format (optional):
   ```bash
   npm run convert-images
   ```

### 📚 Documentation

Detailed documentation on how to make changes, structure your data, optimize images, and manage the deployment pipeline can be found in our comprehensive developer guide:
👉 **[View the Development Guide](./development.md)**

### 🎨 Custom Images

To use custom images instead of online URLs:
1. Place your images in the `public/images/` directory
2. Update the image paths in `src/constants.ts` from URLs to local paths like `images/your-image.webp`
3. Run `npm run convert-images` to optimize them to WebP format
